## 🌟 أبرز المزايا والوظائف

1. **الرئيسية (Dashboard):**
   - متابعة لحظية لـ 7 مؤشرات مالية: رصيد النقدية، رصيد المحفظة، إجمالي الرصيد، رصيد المخزون بالتكلفة، الفلوس اللي لينا، الفلوس اللي علينا، وإجمالي المصروفات.
   - كارت رأس المال التشغيلي التراكمي: `= النقدية + المحفظة + الفلوس اللي لينا + المخزون بالتكلفة − الفلوس اللي علينا`.
   - تنبيهات استباقية: الأوردرات المتأخرة (10+ أيام)، تذكير النسخ الاحتياطي (3+ أيام)، ونواقص المخزون.
   - تعديل سريع للنقدية والمحفظة (`quickAdjust`) للإيداع والسحب اليدوي.

2. **الأوردرات والمبيعات (Orders):**
   - تمييز ذكي بين بنود المخزن (`stock`) وبنود الشراء الخارجي من الموردين (`supplier`) مع خيار التحويل اليدوي.
   - تجميد تكلفة البضاعة المباعة لحظة حفظ الأوردر لضمان عدم تأثر أرباح الشهور السابقة.
   - معاينة لحظية لإجمالي البيع، التكلفة، وصافي المكسب.
   - كشف حساب فوري للعميل مع مؤشرات الديون والمدفوعات.
   - قائمة الشراء لليوم مجمعة بأسماء المحلات مع وضع الطباعة.
   - قفلة اليوم (`Day Closing`) لحساب أرباح اليوم الفورية ومشتريات المخزون.

3. **المخزون والمشتريات (Inventory):**
   - توليد أكواد تلقائية للمنتجات (`BH-XXX`).
   - تطبيق معادلة متوسط التكلفة المرجح المتحرك (**Moving Weighted Average - MWA**) عند كل شراء جديد.
   - دعم الشراء (كاش / محفظة / آجل).
   - سجل مشتريات وسداد دفعات الموردين.
   - أرشفة آمنة للمنتجات تحمي الحركات المالية والدفاتر القديمة من الحذف الخاطئ.

4. **الفلوس اللي لينا (Receivables):**
   - تجميع مديونيات العملاء من الأوردرات غير المسددة مع السندات اليدوية.
   - كشف تفصيلي بالعمليات مع تسجيل دفعات التحصيل (كاش أو محفظة).

5. **الفلوس اللي علينا (Payables):**
   - تجميع التزامات الموردين من المشتريات الآجلة مع السندات اليدوية.
   - سداد الدفعات وتوثيق وسيلة السداد.

6. **المصروفات التشغيلية (Expenses):**
   - تسجيل المصروفات بالبيان والوسيلة وتاريخ الصرف.
   - تحذير استباقي في حال كان الرصيد سينخفض إلى السالب.

7. **الخزنة ودفتر اليومية (Treasury / Cash):**
   - سجل موحد لكافة المقبوضات والمدفوعات للنقدية والمحفظة.
   - حماية القيود التلقائية من التعديل أو الحذف المباشر لضمان النزاهة المحاسبية.

8. **الفواتير الذكية (Invoices):**
   - تجميع أوردرات العميل لنفس اليوم في فاتورة واحدة ودمج البنود المتطابقة.
   - توليد وتصدير صورة PNG عالية الدقة للفاتورة.
   - إرسال مباشر عبر واتساب كصورة أو نص جاهز.

9. **التقارير وتحليل الأداء (Reports):**
   - تقرير إجمالي وتقارير تفصيلية بفلترة متعددة الأبعاد.
   - تحليل الشغل التراكمي (أفضل الشهور ربحية، والمنتجات والعملاء الأكثر مبيعاً).

10. **النسخ الاحتياطي وفحص البيانات (Backup & Data Check):**
    - تصدير واستيراد JSON متوافق مع كافة الإصدارات.
    - تصدير مصنف Excel متعدد أوراق العمل (`.xlsx`).
    - أداة فحص سلامة البيانات لكشف الأرصدة السالبة أو الأسعار الصفرية.

11. **سلة المحذوفات (Trash):**
    - حذف مؤقت آمن لكافة السجلات مع استرجاع متسلسل يعيد حقن قيود الخزينة بدقة.

12. **وضع الصلاحيات (Owner vs Employee):**
    - زر تبديل في الهيدر لإخفاء أرقام رأس المال والأرباح عن شاشات الموظفين أثناء البيع.

## 🚀 التثبيت والتشغيل المحلي

### المتطلبات
- Node.js (v18 فأحدث)
- npm أو pnpm أو yarn

### خطوات التشغيل
```bash
# 1. تثبيت الحزم
npm install

# 2. إنشاء وتحديث قاعدة البيانات
npx prisma db push

# 3. تغذية الإعدادات الافتراضية
npm run db:seed

# 4. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على [http://localhost:3000](http://localhost:3000)

### بناء نسخة الإنتاج
```bash
npm run build
npm start
```
